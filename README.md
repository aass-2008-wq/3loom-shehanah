# رحلة الحياة

مشروع شيهانة مقرن المطيري في مادة العلوم، الصف الثالث الابتدائي.

دورة حياة الضفدع والجمل: رسوم مدمجة، شرح صوتي باستخدام صوت الجهاز العربي، مقارنة، ومسابقة تفاعلية من ستة أسئلة.

لتفعيل النشر: Settings → Pages → Deploy from a branch → main → / (root) → Save.

الرابط بعد التفعيل: https://aass-2008-wq.github.io/3loom-shehanah/

تم التحقق من حساب درجات الإجابات الصحيحة والخاطئة، منع تغيير الإجابة بعد اختيارها، وإعادة المحاولة. العرض والأصوات يحتاجان تجربة على الجهاز؛ النطق العربي يعتمد على أصوات المتصفح المتوفرة.

الموقع عرض مرافق للمجسم المطلوب من خامات المنزل. يتضمن فكرة بسيطة لتنفيذ المجسم.
